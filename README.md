# 环庐1号 · 合肥旅游公路 WebGIS

数据更新：2026.09.22。交互地图包含7个旅游路线图层、191条景点记录、交通服务及可切换的参考路网。

所有路线长度以最新矢量几何测量为准，采用用户指定WGS 84 / UTM zone 50N（EPSG:32650）平面测量，单位米，换算公里展示；同一图层相同坐标边去重，空几何不计里程。报告与旧Excel仅作历史对照。

`index.html` 已内嵌所有页面样式、脚本、路线与景点数据，可通过GitHub Pages发布。在线中文瓦片由天地图提供，仍需联网；原始GeoPackage、QGIS工程和研究报告没有上传。

道路编号优先匹配本次提供的国省道/县乡村专，OSM补充；县界为OSM参考。A级景区沿用上一版，因为本次GeoPackage没有该图层。
